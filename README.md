# Gruppering
En gruppematching-plattform for både studenter og lærere, 
hvor man kan finne, opprette grupper eller opprette courses etter ønsker.


## Run 
1. Opprett .env fil fra sample.env

2. `docker compose -f compose.yaml up -d`

## Testing
`dotnet test`
